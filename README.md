# 🌐 Charles Nextime Web Tools Portal / 教學與應用程式網頁工具箱


這是一個教學和應用程式的輕量化動態網頁工具集。所有工具皆無需安裝，透過瀏覽器即可即時使用。

🔗 **立即造訪門戶網站：[https://w1798.github.io/web/](https://w1798.github.io/web/)**

---

### 🛠️ 工具精選 / Tool Highlights

| 工具名稱 | 功能簡介 |
| :--- | :--- |
| **🗓️ 作業動態曆** | 自動化追蹤與顯示各類課程作業進度。 |
| **💬 評語提詞自造佳** | 協助教師快速生成、組合專業且多樣化的學生評語。 |
| **📋 教學清點小幫手** | 課堂器材、作業收繳或學生到課快速清點工具。 |
| **⏲️ 數位考場看板** | 模擬正式考場介面，顯示考試時間、注意事項與計時。 |
| **💻 專業 JSON 編輯器** | 清晰的結構化資料編輯器，支援語法檢查與縮排美化。 |
| **🔠 多功能文字處理器** | 整合格式轉換、文字清理與快速排版的純文字助手。 |
| **📈 Vercount 數據儀表板** | 視覺化呈現各項工具的使用數據與點擊紀錄。 |
| **💰 股息回本解套記** | 個人股票追蹤，輕鬆計算應得股息，一手掌握配息紀錄與解套進度。 |
| **🎖️ ClassDojo 點數統計** | 能快速處理導出的數據，是高效管理學生表現的最佳助手。 |
| **🏫 學年總課表** | 能自動化整合多班級的 Word 格式課表，大幅提升安排教學活動的效率。 |
| **👁️ 專注追蹤器** | 是一款專為教育工作者與觀察員設計的數位化評估工具。 |
| **👥 家長通訊錄轉換器** | 專為導師設計，能將學務系統匯出的繁雜 Excel 轉化為 Google 聯絡人格式。 |

---

### 🚀 特色 / Features

* **無需安裝**：純 HTML/JS 開發，開啟網頁立即使用。
* **響應式設計**：支援電腦與平板(手機)操作，適配教學場域。
* **資料安全**：本地瀏覽器執行，資料不留雲端(部分支援自設雲端帳號，可異地使用)，保障隱私。
